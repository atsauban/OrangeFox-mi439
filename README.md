# OrangeFox Recovery Project R12.0_1 (Unofficial)

Unified build for Xiaomi Redmi 8 / 8A / 8A Dual / 7A (`mi439`: `olive`, `olivelite`, `olives`, `pine`, `olivewood`).

- **Maintainer**: atsauban
- **OrangeFox Version**: R12.0_1
- **Manifest Base**: fox_12.1-R
- **Kernel Base**: Linux 4.19 (with backward compatibility)
- **Build Type**: Unofficial
- **Date**: 2026-10-07

---

### Features & Working
- Full unified `mi439` support (`olive`, `olivelite`, `olives`, `pine`, `olivewood`)
- Support flashing Android 10, 11, 12, 13, 14, 15, 16, and 17 ROMs
- Dynamic Partition & Retrofit auto-detection
- Touchscreen support (FocalTech & Novatek)
- Persistent OrangeFox settings, Dark Theme, and gestures
- Flashlight / Torch auto-detection
- Backup & Restore with digest verification
- Recovery PIN/Password protection
- MTP and ADB sideload
